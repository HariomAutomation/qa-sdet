# 🛡️ Visual Regression, Accessibility & Security Automation Suite

Specialized automated test suite providing continuous compliance checks across visual regressions, WCAG 2.1 AA accessibility guidelines, and OWASP security vulnerability vectors.

## 🚀 Running Suites

```bash
# Run automated accessibility scan
npm run test:a11y

# Run automated security scans
npm run test:security

# Run all suites
npm run test:all
```
