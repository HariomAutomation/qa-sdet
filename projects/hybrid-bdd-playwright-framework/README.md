# 🥒 Hybrid BDD Cucumber + Playwright Framework

Enterprise-grade Behavior Driven Development (BDD) test automation framework seamlessly combining Gherkin business feature files, Cucumber.js, and Playwright for TypeScript.

## 🚀 Running BDD Tests

```bash
# Run all feature scenarios
npm run test:bdd

# Run only smoke scenarios
npm run test:smoke

# Run regression scenarios
npm run test:regression
```
